# ADR-001 事件溯源作为唯一事实来源

- 状态：已接受
- 日期：2026-11-07

## 背景

多 Agent 并发系统的头号工程痛苦是"现场无法复现"。上游原型的状态藏在关系表与内存对象里（Engine 的聚合），方法调用顺序即时间，出事要靠人脑模拟。

## 决策

一切状态 = 总线上事件的物化视图；总线是唯一写入口（append-only SQLite）；`seq` 全序 + `caused_by` 因果；非确定性（LLM/时钟）以事件形式记录，重放用记录值。

## 后果

- 正面：任意行为可回放复现；Watchdog/信用/怒气天然有事实源；调试=读事件流。
- 负面：写放大（每笔操作多一次事件记录）；重放依赖记录值完整性（LLM 响应全存，blob 增长要有清理策略——哈希引用+按期归档）；所有组件必须无隐藏状态（这是纪律成本，值得）。
- 放弃的替代：上游式聚合存储（成熟但不可回放）；纯内存总线+旁路日志（日志不是事实源，会漂）。

# ADR-002 看门狗输入收口：永不喂自由文本

- 状态：已接受
- 日期：2026-11-07

## 背景

监督者被被监督者的输出喂着，是提示注入的天然攻击面（上游文章承认凭据风险但未讨论此面）。同时自由文本上下文成本高、判断不稳定。

## 决策

皮层输入只能是强类型遥测（数字/枚举/id/HooH 裁决记录），schema 校验超字段即丢；皮层输出的文字证据只进审计链给人看，永不回流为任何 LLM 的输入。Worker 报告在进皮层前压缩为枚举+数字。

## 后果

- 正面：注入面收口到"HooH 裁决记录的完整性"（HMAC 链保护）；皮层判断稳定可比较；token 成本低。
- 负面：皮层判断力受限（看不到任务内容）——刻意为之：方向漂移在遥测差分里可见（目标步数、产出物变化率），不需要读内容；真需要读内容时升级给人。
- 放弃的替代：喂摘要文本（更聪明但开注入面）；双通道（结构化+文本交叉验证）——v1 不做，记为未来 ADR。

# ADR-003 乐观执行分级：只读白名单可抢跑

- 状态：已接受
- 日期：2026-11-07

## 背景

异步内核下模型可选择"不等结果先走下一步"（继承 jinchen-fd 半句抢答姿态）。但语音猜错=重说一句话，Agent 猜错=执行错误的工具序列，代价不对称。

## 决策

乐观执行按工具副作用分级：
- **只读白名单**（read/glob/grep/test/status）：可乐观并发，猜错=重读，无代价；
- **写类**（write/edit/exec-写/网络发）：必须等依赖落定，禁止乐观；
- 猜错修正=口吃回合（明说假设错了→重规划），口吃不计入熔断计数（它是正常姿态不是故障）；
- 会话级开关与预算（乐观并发数上限），Worker 提示词明示白名单。

## 后果

- 正面：等待时间转化为并行度；"口吃"成为可观测、可统计的正常行为（口吃率进遥测）。
- 负面：白名单维护成本（新工具默认不乐观——fail-close）；乐观读的浪费成本（有 meter 计量）。
- 放弃的替代：全乐观（代价不可控）；全悲观（退化回同步 ReAct）。

# ADR-004 跨语言边界：纯算法移植 TS，执行边界留协议

- 状态：已接受
- 日期：2026-11-07

## 背景

既有资产 Python（jcf/HooH/aitoolkit），内核选 TypeScript（上游同栈、异步生态）。热路径（每事件过滤+信用查询）跨进程调用会放大延迟一个数量级。

## 决策

- **移植**（TS 重写，MIT 兼容、零 I/O）：rule_gate（含 SafeEvaluator 白名单求值器）、ambiguity_router、trust_tier（信用/怒气状态机）、SimHash 判重。移植时逐模块写"对应原件+差异声明"进注释（910 约定）。
- **不移植、只协议对接**：HooH-MCP（裁决/快照/沙箱）保持 Python 原样一行不改。
- **不移植也不对接**：aitoolkit/jcf 的会话入口层与 UI（历史使命已完成，只取思想）。

## 后果

- 正面：热路径零跨进程序列化；HooH 的安全属性（纯标准库、经审计）原样保留。
- 负面：两处实现漂移风险——用"原件文件路径+版本+行为差异"注释锚定，P3 时对拍一轮移植件与原件的行为一致性（同输入同输出表）。
- 放弃的替代：全 Python 内核（放弃上游同栈对照的便利）；全 TS 重写 HooH（重写安全边界=重蹈"被审计方自己可写记录"的覆辙，绝对禁止）。
