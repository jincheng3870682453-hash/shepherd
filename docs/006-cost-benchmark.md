# 006 成本护栏与基准试验台

> 两个横切件：管钱的（电表/闸/熔断）和管真相的（临床试验）。基准从 P1 起就要能跑——临床试验是设计的一部分，不是验收时的补考。

## 1. 成本记账

**计量点**：每次 LLM 调用（input/output/cache token × 模型单价）、每次诱饵后验、每次 Watchdog 皮层唤醒、每次投机任务——全部以 `meter.charge{session, model, tokens, cost_usd, caused_by}` 入总线。

**模型分档**（v1 = DeepSeek API，价格按官方牌价进配置）：

| 角色 | 模型档 | 理由 |
|------|--------|------|
| Router / 受理评估 | chat 档 | 上游实测：Router 层任务不复杂，轻模型兼顾速度与效果 |
| Worker | reasoner 档 | 执行质量决定交付 |
| Watchdog 皮层 | chat 档 | 只做三值判断 |
| 测试与基准 | mock 回放 | 零成本、可重复 |

## 2. 护栏（电表→闸→熔断）

- **分电表**：每会话独立记账；单会话超预算（默认 Worker $2/Task，Router $5/日）→ 该会话降速（批量合并、禁乐观执行）而非直接杀。
- **总闸**：全局日预算（默认 $10/日，可配）→ 超限**熔断**：停新受理、在途任务降级为只读收尾、面板红色告警、等人。
- **投机预算**：全局投机池独立于主预算（默认 20%/日），按信用函数分配（004 §3），池干涸即投机静默——投机永远不挤占正式工作。
- **熔断恢复**：只能人来解（面板/CLI），自动恢复=失控。
- **降级原则**：任何护栏动作本身是事件（`meter.tripped`），进审计链。

## 3. 基准试验台设计（临床试验）

### 病人与对照组

| 组 | 配置 | 回答的问题 |
|----|------|-----------|
| A：完整 Shepherd | 双层+Watchdog+信用+投机 | 主实验组 |
| B：无监督 | 同 A 但 Watchdog 关闭 | Watchdog 的增量价值 |
| C：上游复刻 | 单 Session+Subagent 工具（对齐上游实验设置） | 与上游结论可比性 |

### 试验剧本（每个剧本=事件流+故障注入+判分断言）

| 剧本 | 注入 | 主要指标 |
|------|------|---------|
| S1 基线吞吐 | 无（300 消息/20 请求，对齐上游） | p50/p95 完成时间、token 总耗 |
| S2 死循环 | 1 个 Worker 陷入相同错误循环 | 漏放率、止损时间、恢复后交付率 |
| S3 缓慢偏题 | 1 个 Worker 每步成功但方向偏 | 皮层检出率、误杀率（对照 S6） |
| S4 深思考 | 1 个 Worker 故意 25min 无输出后高质量交付 | **误杀率（必须≈0）** |
| S5 洪水+毒评论 | flood + poison 混合 | 过滤率、注入拦截率、成本涨幅 |
| S6 诱饵验证 | 2 个 Worker 中 1 个谎报 ready | 后验捕获率、信用变化曲线 |
| S7 投机窗口 | 群里讨论 Bug 的 15min 窗口 | 投机命中率、打扰率、token 效率 |

### 流程纪律

- 每剧本×每组跑 5 次（对齐上游实验惯例）；LLM 全走 mock 回放（录制的真实 API 会话样本），保证可重复、零成本；最后挑 1 组真实 API 复跑验证 mock 结论不失真。
- 判分器只认事件总线与 blob 证据（交付物哈希、诱饵回归输出），不读 LLM 自述——判分器本身要过"指标游戏检测"（继承 work.py AST 签名思想：检查 Worker 是否删测试/改断言来骗分）。
- 产出四张表：完成时间、误杀率/漏放率、成本、打扰率（每任务对人类的消息数）。

## 4. 成功判据（与 000 §4 呼应，这里是可执行的口径）

1. S4 误杀率 ≤ 1/15（5 次×3 组里最多咬错 1 次）；
2. S2 漏放率 = 0，止损时间 ≤ 10min；
3. S1 中 A 组 p95 显著优于 C 组（方向对齐上游结论），成本溢价 ≤ 2.5×（上游多会话成本大约 1.5~2×，我们含监督留 0.5× 余量）；
4. S6 后验捕获率 = 100%（诱饵机制是确定性的，不允许漏）；
5. S7 命中率有数字且打扰率 ≤ 1 条/机会（"安静原则"）。
