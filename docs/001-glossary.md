# 001 术语表（Glossary）

> 认字先行。每个词给出定义与"不是什么"。沿用上游原型能对齐的概念尽量对齐（便于对照实验）。

## 核心域对象

| 术语 | 定义 | 不是什么 |
|------|------|----------|
| **事件（Event）** | 系统中唯一的事实单位：已发生的事。含唯一 `id`、`type`、`ts`、`producer`、`caused_by`、`payload` | 不是命令（命令是"要发生"，事件是"发生了"）；不是消息（消息是事件的传输形态之一） |
| **总线（Bus）** | 事件的持久化存储与顺序发布点。追加写、全序、可回放 | 不是队列（消费者各自记账，不取走事件）；不是数据库表集合（只有一张事实表） |
| **会话（Session）** | 消费事件的 LLM 状态机实例：有自己的队列、上下文窗口、身份 | 不是聊天记录（记录是会话的产物之一）；不是进程（进程是宿主，会话是逻辑身份） |
| **Router** | 常驻轻模型会话：过滤后事件的唯一分派者与对外发言人 | 不干活（无写类工具）；不是唯一 LLM（Worker 各有强模型） |
| **Worker** | 执行具体任务的隔离会话：独享上下文、目录、HooH 裁决边界 | 不直接对外说话（一切输出经 Router）；不是一个进程里的线程 |
| **Ticket** | 一个工作单元的生命周期记录：从被受理到结束，挂有自己的事件流 | 不是任务描述（描述是 Mandate）；不是会话（Ticket 在，会话可死可换） |
| **Mandate** | 工作单元的授权范围：允许做什么、边界在哪、何时失效 | 不是提示词（提示词教方法，Mandate 划权限） |
| **Thread** | 事件流主题：一个 PR、一个话题、一个工单下的事件序列 | 不是会话；不是群聊（群聊是 Thread 的来源之一） |
| **Subscription** | Thread→Worker 的直通关系：后续事件绕过 Router 直达 | 不是全量广播（只有订阅者收到） |
| **Trigger** | 进入系统的原始环境事件（未过滤） | 不是 Trigger 之后的一切（触发≠受理） |

## 看门狗词汇

| 术语 | 定义 | 不是什么 |
|------|------|----------|
| **看门狗（Watchdog）** | 主系统外部的独立监督回路：吃遥测，产判断，经确定性裁决执行介入 | 不是进程管理器（systemd 只管死活）；不是日志分析器 |
| **脊髓（Spinal reflex）** | 确定性规则层：纯代码、零 LLM、不可被注入 | 不理解语义（只认信号模式） |
| **皮层（Cortex）** | 模型判断层：独立会话，只读结构化遥测，输出三值判断 | 没有执行权（只提议）；不吃自由文本 |
| **遥测（Telemetry）** | Worker 行为的结构化信号：报告间隔、连续同错次数、同文件编辑次数、token 斜率、HooH 拒绝计数 | 不是日志文本（文本不进皮层） |
| **实质进展（Substantive progress）** | 一次改变系统可验证状态的行为：写操作落地、测试结果变化、诱饵状态变化。**读类操作不算**（继承 HooH STALL 规则） | 不是"模型说它进展了" |
| **介入（Intervention）** | Watchdog 的动作，分级：`observe`→`nudge`（注入提示）→`restart`→`escalate`（给人） | 不是惩罚；不可跳级（escalate 必须记录为何 nudge 不够） |
| **怒气（Anger）** | 介入额度的连续状态机（0-100，继承 jcf GrudgeMode）：介入+30，正常衰减-16/轮，时间衰减-10/30s；怒气决定下次介入的灵敏度与额度 | 不是硬计数器（那是我最初设计，已废弃） |

## 信用与诱饵词汇

| 术语 | 定义 | 不是什么 |
|------|------|----------|
| **信用（Credit）** | 实体（Worker/信息源）的历史守约度。双层：基础信用（慢）+ 当前信用（敏感，会话开始时 = 基础-5，继承 jcf v2.1） | 不是权限（信用调阈值/预算，不给权限） |
| **守约（Kept promise）** | 报告"ready"且经后验为真；或报告"blocked"且理由被证实 | 不是"没报错" |
| **诱饵（Bait）** | 刻意埋放的已知缺陷/探针任务，用于后验"报告为真"（继承 Word体系 BaitPool） | 不是陷阱（不诱导做坏事，只验证能力与诚实） |
| **诱饵后验（Bait verification）** | 报告"测试全过"→ 实际跑带诱饵的回归，诱饵未被捕获 → 该报告记为不实，信用降 | 不是每个任务都埋（有成本，按信用与任务级别决定埋不埋） |
| **后验采样率** | 对某 Worker 抽样做诱饵后验的概率，随信用降低而升高 | 不是 100%（全查太贵） |
| **预算函数（Budget function）** | `budget = f(credit)`：投机预算、介入额度、后验采样率都是信用的函数 | 不是常数；不是手动配置 |

## 异步内核词汇

| 术语 | 定义 | 不是什么 |
|------|------|----------|
| **异步工具（Async tool）** | `start()` 立即返回句柄的工具调用；结果完成后作为事件投递回会话 | 不是 fire-and-forget（句柄可 stop，结果必达） |
| **句柄（Handle）** | 后台任务的引用：可查、可 stop、结果注入时携带 | 不是进程号 |
| **步间注入（Inter-step injection）** | 结果事件只在模型推理步之间进入上下文，永不打断生成中的回复 | 不是插入历史任意位置 |
| **乐观执行（Optimistic execution）** | 结果未回时先推进下一步，猜错则"口吃"修正。分级见 ADR-003：只读白名单可乐观，写操作必须等 | 不是赌博（有白名单与预算） |
| **口吃（Stutter）** | 乐观猜错后的修正回合：明说"刚才假设错了"，然后重规划（继承 jinchen-fd 姿态） | 不是失败事故；不计入熔断 |
| **归档（Archive）** | 已完成任务的启动过程压缩为摘要，腾出上下文（SimHash 判重，继承 Archive.py） | 不是删除（原文在事件总线，可回放） |

## 系统词汇

| 术语 | 定义 | 不是什么 |
|------|------|----------|
| **裁决（Adjudication）** | HooH 对每次工具调用的判定：放行/询问/拒绝/沙箱执行 | 不是 Shepherd 自己的逻辑（边界全在 HooH） |
| **审计链（Audit chain）** | HMAC 链式事件日志：改一条即断链（继承 jcf audit_log + HooH） | 不是普通日志 |
| **分电表（Meter）** | 会话级 token/成本记账；**总闸**：全局日预算；**熔断**：超限即停新不开旧 | 不是月底账单（实时） |
| **模拟源（Mock source）** | 生成合成事件流的源：可注入故障（死循环、偏题、假死、洪水） | 不是造假数据（是临床试验的病人） |
| **Would-do 日志** | 投机任务被丢弃/降级时的记录：本来会做什么、为何丢弃 | 不是垃圾（是命中率仪表盘的数据源） |
| **生产者（Producer）** | 事件的真实来源标识。**事件必须指认生产者而非症状**（继承 ace_ledgers H-21 教训） | 不是转发者 |
