# 004 信用与诱饵（Credit & Bait）

> 旗舰特性二：用"诱饵后验"给信用体系一个不依赖自报的真值锚点，再用信用驱动一切预算。这两个概念上游文章与原型均无。

## 1. 信用体系（继承 jcf trust_tier v2.1）

**实体**：每个 Worker 会话、每个信息源（GitHub 仓库/模拟源角色）各一个信用档案。

**双层结构**（参数继承 jcf，v1 原样，跑通后再调）：
- **基础信用** `base(0-100)`：大时间尺度慢变。新实体默认 30。
- **当前信用** `cur = base - penalty`：会话开始 `penalty=5`；会话内即时事件直接作用在 cur 上；会话结束按比例回写 base。
- **时间衰减**：长期不活跃的实体，base 向 30 缓慢回归。

**加减分表**（初版，全部走 `credit.changed{entity, delta, caused_by}` 事件）：

| 事件 | Δcur |
|------|------|
| 报告 ready 且后验为真（含诱饵未抓出逃逸） | +8 |
| 报告 blocked 且理由被证实（复现/证据） | +3 |
| 报告 ready 但后验不实（诱饵在而声称全过） | -25 |
| 被脊髓 nudge 后 10min 内恢复实质进展 | +2 |
| 被 restart（无论最终成败） | -10 |
| restart 后重犯同一问题指纹 | -15 |
| HooH 拒绝（试探边界）每次 | -4 |
| Watchdog 漏放由人手工止损 | -20 |
| 洪水/垃圾事件的信息源 | 源信用 -5/次 |

## 2. 诱饵后验（继承 Word体系 BaitPool + AST 签名思想，泛化为任务级）

**原则（Word体系原文）**："这套系统不依赖任何 AI 的诚实，它只相信自己的检测逻辑和人类的终审权。"

**三类诱饵**：

1. **代码诱饵**：在 Worker 的工作目录里预埋已知缺陷（如一处故意的作用域错误）。声称"测试全过"→ 实际跑带诱饵的回归：诱饵缺陷未被暴露 = 报告不实。AST/结构签名比对防"删测试/搬代码"绕过（继承 work.py 的移动检测与条件包裹检查）。
2. **探针任务**：Router 在分派真任务时，以低概率（后验采样率）附加一个已知答案的小子任务（例如"这个文件第 N 行有什么"——Router 已知答案）。答案错 = 该会话的报告可信度打折。
3. **环境诱饵**：模拟源周期性投放已知问题（模拟 Bug 报告，带已知复现与修复路径）。作为整条链路的端到端验证：从触发到修复到后验全绿才算一次"真守约"。

**采样策略**：`后验采样率 = 1 - credit/120`（信用 100 → ~17% 抽查；信用 30 → 75% 全查；新实体高查）。诱饵成本记账进 meter（查也是钱）。

**红线**：诱饵绝不诱导作恶（不埋"贿赂点"），只验证能力与诚实；诱饵的存在对 Worker 保密程度分级——代码诱饵完全保密，探针任务在 Mandate 里明示"本任务可能含验证子项"（对齐 Word体系"后验"而非"钓鱼"的精神，避免训练出防摸鱼表演）。

## 3. 预算函数（信任是预算的函数）

| 消费点 | 函数 |
|--------|------|
| 投机预算（每源每日 token） | `spec_budget = 50k × (credit/100)²`（平方：低信用几乎清零） |
| 后验采样率 | 上节公式 |
| Watchdog 阈值乘数 | `×(1.6 - 0.9×credit/100)`（信用 100→×0.7 更耐心；30→×1.33 更严厉） |
| 并发 Worker 槽位权重 | 高信用实体的会话在槽位竞争中优先 |
| 消息直通率 | 低信用源的 Trigger 不走直通，强制回 Router 复审 |

**不可信用化的事项**（写死，不进函数）：写权限、审计豁免、熔断豁免——信用只调"耐心与预算"，永远不买"绕过边界"。对齐 HooH 哲学。

## 4. 信息源信用

GitHub 仓库/模拟源也有信用：产出垃圾 Trigger（被皮层/Router 判定无关）→ 源信用降 → 该源的过滤阈值收紧（rule_gate 规则热更新）→ 最终可能自动降到"只响应 @提及"。洪水源的最终形态=自动断粮。这一层让入口过滤从静态规则变成**自适应的**。

## 5. 与上游对照

| 机制 | 上游原型 | Shepherd |
|------|---------|----------|
| 准入 | 静态白名单+准入表 | 白名单 + **源信用自适应阈值** |
| 受理后信任 | 无（报告即事实） | **报告≠事实，后验采样校准** |
| 预算 | 全局 worker 槽位 | 槽位 + **信用化投机预算/阈值** |
| 监督 | 无 | Watchdog 阈值随信用自适应 |
